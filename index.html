Supported scope

      
The inspector reads MVP types, imports, functions, tables, memory, globals, exports, start, active element segments, data and custom sections, and it also accepts the post-MVP data-count section, passive and explicitly indexed data segments, and multiple tables and memories. Element segment flags 1 through 7, reference types beyond funcref and externref, the typed select opcode, shared memory, 64-bit memory and newer prefixed instruction families produce a named error.

      
The tracer executes i32 arithmetic, bit operations, comparisons, locals, direct calls, blocks, loops, conditionals and branches. It stops on unsupported instructions or a resource limit. Imported functions and module start functions are never executed. Results are checked against native execution in the test suite.

      
All input stays in this page. The text listing is an inspection output; this tool does not assemble text or replace a complete runtime.
